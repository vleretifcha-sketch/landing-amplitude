# Landing Amplitude

Landing page premium et minimaliste pour une application de souplesse & mobilité (approche fitness).

## Démarrage

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Stack

- React 19 + Vite 6
- Tailwind CSS v4
- Typographie : Cormorant Garamond + Jost

## Personnalisation

- Nom de marque : rechercher `Amplitude` dans `src/App.tsx` et `index.html`
- Couleurs : variables dans `src/index.css` (`@theme`)
